# Study Haven

A cozy Arabic-first study planner for Android.

## Features
- Daily tasks with notes, completion state, and automatic local saving.
- Focus timer and selectable break durations.
- Optional local audio playback from a file on the device.
- Calm pastel interface inspired by the visual reference.

## Build
The GitHub Actions workflow builds a debug APK on pushes to `main` and manual workflow dispatches.

Artifact name: `study-haven-debug-apk`
